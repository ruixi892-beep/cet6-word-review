# 词频手册

个人 CET-6 复习网页。词条按已收录六级真题中的出现次数排序。同频词按出现考期数、字母顺序排列。

- 高频筛词：先回想词义，选择「会」或「不会」。后者会加入生词库。
- 今日复习：一组最多 6 个到期词。回想词义后做拼写，记忆与拼写均通过才延长间隔。
- 词库：按词、释义、考试标签和学习状态查找。
- 资料与进度：查看考期覆盖、统计口径，以及导出和导入个人学习进度。

进度保存在当前浏览器。导出 JSON 后可以在另一设备导入。发音由浏览器的英语语音提供。

## 数据来源

词频和跨场连用统计基于桌面资料包的卷面文字，涵盖可读取 PDF 文字层和已识别的扫描图版。去除常见基础词、考试说明和同场重复的英语句段，并归并常见词形。音频本身未转写。考期及缺口详见 [coverage.json](coverage.json)。

中文释义、音标和考试标签来自 [ECDICT](https://github.com/skywind3000/ECDICT)。考试标签是词表编者提供的备考参考，重叠时显示最早一级。参见 [MIT 许可证](ECDICT-LICENSE.txt)。

标记为 Tatoeba 的学习例句源自 [Tatoeba](https://tatoeba.org)，每张卡片链接原句并标明许可，采用 [CC0](https://creativecommons.org/publicdomain/zero/1.0/) 或 [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/)。
